## Hi, I'm solorankstreet! 👋

I write Rust and C, usually in that order, and spend an unreasonable amount of time thinking about memory layout. Most of what I build lives in the terminal or runs close enough to bare metal that I can feel the warmth. Lately I've been dragging old CLI tools into the WebAssembly era, which is either visionary or unhinged depending on who you ask.

#### What I do

- 🔭 Rewriting a terminal emulator in Rust because the last one wasn't fast enough.
- 🧩 I like small tools that do one thing well
- 🌍 Based in Japan
- ✨ I prefer boring solutions that work
- ⚡ Fun fact: I debug faster with music on
